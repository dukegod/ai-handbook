# 投融资动态

> **TL;DR**：看投融资不是为了抄作业，是为了读风向——钱流向哪个环节，说明哪个环节有真实需求。

⏱ 预计阅读时间：5 分钟

## 你能在这里学到

- 权威数据源与它们的区别
- 一条融资新闻该读什么、不读什么
- 投融资信号的正确用法

## 一、数据源

| 来源 | 类型 | 特点 |
| --- | --- | --- |
| Crunchbase | 英文一级市场数据库 | 数据全，更新快，覆盖全球 |
| PitchBook | 英文一级市场数据库 | 偏机构用户，深度报告多 |
| IT 桔子 | 中文一级市场数据库 | 国内创投信息最全 |
| 机器之心 / 量子位 | 中文媒体 | 快但需核对金额与投资方 |
| 各公司官方公告 | 一手 | 最权威，但选择性披露 |

> **核对原则**：金额、估值、投资方三个数字至少两个能对上再采信。

## 二、一条融资新闻读什么

**读**：

- 轮次与金额 → 判断阶段（种子 / A / B / C+）
- 投资方 → 是谁在押注（产业资本 vs 财务资本）
- 资金用途 → 研发 / 商业化 / 算力
- 被投方现有产品 → 技术路线验证

**不读（或不作为决策依据）**：

- 估值数字本身（水分大）
- 「AI 概念」光环（很多是传统业务贴 AI 标签）
- 单笔新闻的短期炒作

## 三、怎么用投融资信号

**对技术决策者的正确用法**：

- **赛道热度**：某环节融资密集 → 说明需求真实，工具生态会快速完善
- **商业化验证**：从「烧钱研发」转向「收入增长」的融资 → 商业化拐点信号
- **人才流向**：资金密集处人才聚集，可选型参考

**错误用法**：

- 用融资额判断技术优劣（融资多 ≠ 技术好）
- 用融资新闻决定要不要换技术栈

## 四、速报写法

与 [月度产品速报](/ai-trends/product-updates/monthly) 共用条目模板，四要素：**事件 + 时间 + 影响 + 判断**。

```markdown
## [公司] 完成 [轮次] 融资（金额）

- **时间**：2026-08-XX
- **投资方**：...
- **资金用途**：...
- **判断**：对「XX 环节」是正/负信号，因为 ...
```
