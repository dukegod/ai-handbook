# 百度文心

> **TL;DR**：百度把文心定位为「原生全模态」大模型——搜索 + 云 + 千帆生态是它的护城河，论坛热度低但企业接入不可低估。

## 一、定位

百度的 AI 策略是**基础设施化**：模型 + 千帆平台 + 百度云 + 搜索场景绑定。文心系列在真实业务与企业接入层面推进快，但论坛讨论热度不如开源厂商集中。

## 二、模型线（截至 2026-08）

| 模型 | 说明 |
| --- | --- |
| **ERNIE 5.0 正式版** | 当前商业旗舰，定位「原生全模态」 |
| **ERNIE X1.1 Preview** | 推理增强预览 |
| **ERNIE 4.5 Turbo** | 轻量档 |
| **ERNIE 4.5（开源）** | 公开开源主线（PaddlePaddle/ERNIE） |

## 三、关键事实

- **原生全模态**：文心 5.0 官方定义为「原生全模态大模型」
- **千帆 Coding Plan**：已推出面向 Claude Code 等工具的 Coding Plan，推动 OpenClaw 部署（企业微信 / QQ / 钉钉场景）
- **搜索生态**：百度搜索与文心深度绑定

## 四、特点

- **搜索 + 云绑定**：文心嵌进搜索与云服务，获客渠道稳定
- **全模态 + 推理双线**：5.0 做全模态，X1.1 做推理
- **开源滞后于商业线**：开源主线仍停留在 4.5 家族

## 五、适合 / 不适合

**适合**：百度生态内企业、需要国产化 + 云 + 搜索组合的场景、合规要求高的国内客户。

**不适合**：开发者优先的开源选型（开源版本滞后）、追求技术前沿基准的场景。
